## 技術構成

- HTML / CSS / JavaScript のみ（フレームワーク不使用）
- ホスティング: GitHub Pages
- CSV整形ツールはすべてブラウザ内で処理（データはサーバーに送信されません）
- アクセシビリティ配慮: WCAG AA準拠のコントラスト比、フォーカスリング、スキップナビゲーション
