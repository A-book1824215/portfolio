# IME顔文字・絵文字辞書 配布ツール 設計

## 背景・目的

`C:\dev\ime-emoji-dict\` に、感情語や挨拶をそのまま入力すると絵文字・顔文字が変換候補に出るIMEユーザー辞書（193件、MS-IME形式のテキストファイル）を作成済み。これをポートフォリオサイトの実績カードとしてだけでなく、実際に他人が使えるツールとして配布したい。

目的は実績としての見栄えと実用性の両方（ユーザー確認済み: 「両方（実績兼実用）」）。

## データ

### 語彙データの保管場所

`ime-dict.js` の先頭に配列として持つ。この配列を今後の**公開用の正**とする。

```js
const DICT = [
  { yomi: "うれしい", word: "😊",     type: "emoji",   cat: "emotion" },
  { yomi: "うれしい", word: "(*^^*)", type: "kaomoji", cat: "emotion" },
  // …既存193件を全カテゴリ分移植
];
```

- `yomi`: IME変換の読み（ひらがな、長音記号可）
- `word`: 変換で出したい絵文字または顔文字
- `type`: `"emoji"` または `"kaomoji"`
- `cat`: 下記9カテゴリのいずれか

`C:\dev\ime-emoji-dict\ime_emoji_dict.txt`（原本）は手元の作業履歴として残すが、**今後の語彙追加・修正は `ime-dict.js` の配列に対して行う**。2ファイルの内容が食い違った場合は `ime-dict.js` を正とする。

### カテゴリ（9分類）

| cat値 | 表示名 | 例 |
|---|---|---|
| emotion | 感情・気分 | うれしい、つかれた、なやむ |
| greeting | あいさつ・リアクション | ありがとう、りょうかい、いいね |
| business | ビジネス・敬語 | もうしわけございません、うけたまわりました |
| nature | 天気・季節・自然 | はれ、はる、つき、うみ |
| animal | 動物 | いぬ、ねこ、ぱんだ |
| food | 食べ物・飲み物 | らーめん、こーひー、けーき |
| health | 体調・健康 | いたい、ねつ、びょうき |
| event | イベント・趣味・移動 | たんじょうび、げーむ、でんしゃ |
| emphasis | 記号・強調 | だいじ、ちゅうい、さいこう |

既存193件をこの9カテゴリに機械的に分類し直す（実装時の作業）。

## 画面構成

`qr.html` と同じ「番号付きパネル」形式。3パネル構成。

### 1. 収録する内容を選ぶ（`.tool-panel`）

- カテゴリのチェックボックス9個。初期状態は全選択
- 「すべて選択」「すべて解除」ボタン
- 種類のラジオボタン: `両方`（初期選択） / `絵文字のみ` / `顔文字のみ`
- 選択条件（カテゴリ×種類）に応じて「選択中: ◯件」をリアルタイム表示

### 2. 形式を選んでダウンロード（`.tool-panel`）

- 形式のラジオボタン:
  - `MS-IME用（UTF-16LE・BOM付き）`（初期選択）
  - `Google日本語入力用（UTF-8）`
- 先頭10件程度のプレビュー表（読み／変換される文字の2列）
- ダウンロードボタン
- 選択件数が0件のときはボタンをdisabledにし、`qr-error` パネルと同様の見せ方で「1件以上選んでください」を表示

### 3. 取り込み手順

選んだ形式に応じて手順文を出し分ける（**MS-IMEとGoogle日本語入力は手順が異なるため、ここで確実に区別する**）。

- MS-IME用を選んだ場合: IME右クリック→ユーザー辞書ツール→「テキストファイルからの登録」の手順
- Google日本語入力用を選んだ場合: 辞書ツール→管理→「選択した辞書にインポート」／「新規辞書にインポート」の手順（UTF-8前提。「Microsoft® IME形式を選ぶ」という誤った手順は使わない）

最後に既存ツール同様「ほかのツール」リンク（QR・CSV整形へ）を設置。

## データの流れ・処理ロジック

1. チェック状態から対象語彙を絞り込み（カテゴリ×種類の掛け合わせを `DICT.filter` で実施）
2. 0件なら「1件以上選んでください」表示、ダウンロードボタンをdisabled
3. 形式に応じてテキストを組み立て: `読み\t単語\t品詞` を `\r\n` 区切りで結合（品詞は全件固定で `顔文字`）
4. 形式ごとにBlob化:
   - MS-IME用: UTF-16LEへ変換しBOM（`FF FE`）を先頭に付与してBlob化
   - Google用: `TextEncoder`（標準でUTF-8）でBlob化
5. `<a download>` 経由でダウンロード。ファイル名は `ime_dict_<選択件数>件_<YYYYMMDD>.txt`

### UTF-16LE変換の実装

ブラウザ標準の `TextEncoder` はUTF-8専用でUTF-16LE出力に対応しないため、コードポイントを2バイトリトルエンディアンに変換する関数を自前で実装する。サロゲートペア（一部の絵文字・肌色バリエーション付き絵文字等）を含む文字列を正しく2バイト単位に変換できることが実装上の要点。

## エラー処理

サーバー通信がなく失敗しうる箇所が少ないため、対応するのは以下のみ:

- 選択0件時のダウンロード防止（ボタンdisabled＋エラーメッセージ表示）

ダウンロード自体のブラウザ側エラー（ポップアップブロック等）は、既存のQR/CSVツールでも個別処理していないため、今回も未対応で揃える。

## アクセシビリティ

既存ページと同じ土台に乗るため、以下は自動的に満たされる:
- `<a class="skip-nav">` + `<main id="main-content">`
- 見出し階層（`h1` → `h2` の各パネル見出し）
- コントラスト比・フォーカスリングは既存CSS変数を流用するため新規デザインなし

チェックボックス群・ラジオボタン群には `<fieldset>` + `<legend>` を使い、スクリーンリーダーでグループの目的が伝わるようにする（既存の `.option-row` にはfieldset化された前例がないため、ここは新規対応）。
